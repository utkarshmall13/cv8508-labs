# CV8508 labs

One folder per lab, served with GitHub Pages at `https://<user>.github.io/cv8508-labs/`.

```
cv8508-labs/
  index.html            generated by tools/make_index.py (list of labs, notebooks, data)
  lab1/                 student material for Lab 1
    README.md           first line = title shown on the index
    lab1_pareidolia_student.ipynb
    data/               zips students download (<100 MB each)
  lab2/ ...             same layout
  tools/new_lab.sh      scaffold a new lab and refresh the index
  tools/make_index.py   regenerate index.html
  instructor/           answer keys; listed in .gitignore, never pushed
```

Notebooks download their data from `https://<user>.github.io/cv8508-labs/labN/data/`. Keep each file under 100 MB and the repository under about 1 GB.
